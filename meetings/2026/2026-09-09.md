### Updates

- pnpm monorepo: https://github.com/typeorm/typeorm/pull/12854
  - The PR turns the repository into a real pnpm workspace, with a single lockfile and one place for every published package.
  - We discussed whether the `typeorm` package should stay in the repository root, where it is today, or also move into the `packages` subdirectory.
  - Moving it into `packages` is the correct layout for a monorepo, so it has to happen at some point. The concern was that the file moves would disrupt every open pull request.
  - Decision: move it now. There will always be open pull requests, so waiting does not make the problem smaller.
  - To make the transition easier for contributors, the PR includes scripts and a prompt that pull request authors can use to replay their branch across the move without conflicts.
- Reviewed the pull requests we want to review and merge next:
