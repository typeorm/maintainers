# Plan for 2.0

This document will collect ideas for v2 that cannot be implemented in 1.x due to breaking user behavior. It will be updated based on the discussions in the regular meetings.

## General Architecture
1. Extract drivers into packages. Each driver should correspond to a database client library.
2. Extract loggers and CLI into packages.
3. Drop Node <= 20 (22?) support.

## Specific breaking changes
1. `QueryRunner.stream` should change signature. Event listeners should be grouped in an `options` object and the method should return `Readable` instead of `ReadStream`.
2. `QueryRunner.query` should change signature, an `options` object should replace `useStructuredResult`.
